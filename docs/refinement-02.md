# Refinement 02

Цель прохода: сохранить сильную редакционную композицию Astra, но убрать излишнюю журнальность, улучшить читаемость мелких элементов и подготовить каталог к 50–100+ играм.

## Что изменено

- Навигационное название «Журнал» заменено на более утилитарное «Разборы» без смены URL `/journal`.
- Главный материал на главной теперь называет игру прямо: `Gates of Olympus`, без журнального псевдозаголовка.
- Вторичный материал Reactoonz тоже получил более прямое название.
- Микротипографика увеличена: хлебные крошки, подписи изображений, метаданные каталога, TOC, футер и служебные подписи.
- Каталог стал плотнее в режиме списка: меньше изображения и вертикальные интервалы, описание ограничено двумя строками.
- На широком экране режим обложек показывает три игры в строке.
- Добавлена сортировка по RTP.
- Поиск учитывает название, провайдера, механику и год.
- В списке провайдеров и механик отображается число игр.
- Активные фильтры видны над выдачей и снимаются по одному.
- Для больших каталогов добавлена порционная выдача по 18 игр с кнопкой «Показать ещё».
- Фильтры и панель результатов закрепляются на десктопе без стеклянных/градиентных эффектов.
- На мобильном активные фильтры прокручиваются горизонтально, а выдача остаётся компактной.

## Что сознательно не менялось

- Светлая бумажная палитра.
- Основная редакционная сетка и логика страниц игры.
- URL и структура маршрутов.
- GitHub Pages workflow и статический export.
- Контентная модель. Массовый перенос старого Slotfolio пока не выполнялся.
