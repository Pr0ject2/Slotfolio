# Slotfolio

Новый самостоятельный проект на Next.js 16 App Router, React 19 и TypeScript. Каталог, редакционные разборы и справочник об устройстве слотов. Старый Slotfolio не использовался.

## Запуск

Требуется Node.js 20.9+ (проект проверен на Node 24).

```sh
npm ci
npm run dev
```

На Windows PowerShell при запрете npm.ps1 используйте `npm.cmd`.

Сайт: http://localhost:3000. Производственная версия: `npm run build`, затем `npm start`.

## Что реализовано

- Редакционная главная с основной историей, боковой полосой, игровым указателем и тематическими входами.
- Каталог с архитектурой под 50–100+ игр: поиск по названию, провайдеру, механике и году, фильтры с количеством записей, активные фильтры, сортировка, режим списка / обложек и порционная выдача по 18 игр. Параметры сохраняются в URL.
- Двенадцать полных досье игр: факты, правила, мнение редакции, источники, FAQ и связанные игры.
- Сравнение до трёх игр с сохранением выбора в localStorage.
- Пять механик и пять провайдеров с переходами к отфильтрованному каталогу.
- Тематическая подборка, длинная статья, отдельный гайд о RTP и объяснение бонусных условий.
- GEO-пример для Великобритании, страница проекта, редакционная политика, прозрачность партнёрства, конфиденциальность, ответственная игра.
- Loading, error, 404, метаданные, favicon, skip link, клавиатурный фокус.

## Архитектура

`src/app` — маршруты и серверные шаблоны. `src/lib/data.ts` — типизированные сущности и связи. `src/lib/system-pages.ts` — тексты системных страниц. `src/components/catalog.tsx` — интерактивные сценарии каталога и сравнения. `src/components/editorial.tsx` — повторяемые редакционные элементы, а не универсальная оболочка Card. `src/components/shell.tsx` — навигация и подвал. `src/app/globals.css` — токены и отдельные композиции с правилами для mobile/tablet/desktop.

Данные можно заменить на CMS или репозиторий без изменения публичных slug. При реальном наполнении нужны: серверная выборка с пагинацией, полнотекстовый индекс, несколько механик на игру, схемы валидации источников и редакционные статусы. Текущая фильтрация выполняется на клиенте и уже рассчитана на каталог порядка 50–100 игр. При дальнейшем росте базы нужны серверная выборка, пагинация и полнотекстовый индекс.

## Партнёрская интеграция

Настройки находятся только в `src/lib/affiliate.ts`, серверный переход — `/go/[operator]`. В `.env.local` можно определить `AFFILIATE_1WIN_URL` после проверки адреса и условий. Допускается только HTTPS; без адреса интерфейс показывает справочный переход, а `/go/1win` ведёт на disclosure. После изменения окружения для статических страниц нужна пересборка.

GEO Великобритании намеренно не включает партнёрский переход: локальная доступность 1win не заявлена. Для масштабирования GEO понадобится отдельная матрица оператор / страна / статус проверки. Произвольного URL-параметра для перенаправления нет.

## Проверки

```sh
npm run typecheck
npm run build
# Запустить npm start в отдельном терминале, затем:
npm test
node scripts/screenshots.mjs
```

Playwright использует установленный Chrome. Путь задаётся через `CHROME_PATH` в тестах; по умолчанию указан стандартный Windows-путь. Проверяются маршруты, внутренние ссылки, изображения, поиск, фильтры, сортировка, сравнение, FAQ, мобильное меню, 404, партнёрский fallback и переполнение на 320/390/768/1024/1440 px. Снимки и исследовательские изображения генерируются локально и в чистый GitHub-архив не входят.
