# Refinement 06 - расширение каталога

Версия v116 переводит Slotfolio от маленького демонстрационного набора к более содержательному каталогу.

## Что изменилось

- Каталог расширен с 6 до 12 игровых досье.
- Добавлены Push Gaming, Hacksaw Gaming и Nolimit City.
- Добавлена отдельная механика «Способы» и справочная страница для неё.
- Страницы игр теперь подбирают похожие игры сначала по механике, затем по провайдеру.
- В сравнение добавлены новые готовые наборы для кластерных игр и динамических способов.
- Тексты главной, поиска и README больше не завязаны на старый размер каталога.
- Подпись под изображением досье больше не утверждает, что каждое изображение взято с официальной страницы; официальный источник относится к характеристикам и описанию функций.
- Исправлена нормализация slug для Play’n GO: ссылки профиля и фильтр теперь используют `/providers/play-n-go` единообразно.
