# Визуальная система Slotfolio

## Основа

- Бумага: `#f5f3ed`.
- Текст: `#242622`.
- Вторичный текст: `#66685f`.
- Разделители: `#d1d1c8`.
- Киноварный акцент: `#bd432b`.
- Фон справочных вставок: `#e8e9df`.

Акцент отмечает рубрику, активную навигацию и выбранное состояние. Графика игр остаётся в своих исходных цветах. Градиенты, свечение и стеклянные панели не используются.

## Типографика

Golos Text (локальные начертания 400–800) — интерфейс, данные и основной текст. Georgia — редакционные заголовки, вводные абзацы, цитаты. Логотип — плотное наборное слово с точкой, без случайного символа слота.

Крупный editorial: 58–72 px на desktop, 43–59 px на mobile. Заголовки чтения: 31–35 px. Основной текст статьи: 16 px / 1.85, mobile 15 px / 1.85. Служебная типографика компактная, с разрядкой; на ней не строится основная информация.

## Поля и сетка

Максимальная ширина сайта 1440 px. Боковые поля 56 / 32 / 24 / 20 px. Основные интервалы: 8, 12, 16, 20, 24, 32, 40, 56, 64 px. Читательская полоса до 700 px; рядом отдельное оглавление. Разделы начинаются с линии 2 px, строки отделяются линиями 1 px.

## Изображения

Обложка главной приблизительно 1.9:1, досье 1.58:1; каталог 1.6:1 на desktop. Малый мобильный каталог использует более компактную обложку рядом с названием. Основная графика не накрывается редакционным заголовком. Подписи и пояснения располагаются отдельно. Для большого размещения нужен отдельный качественный исходник, а не растянутая миниатюра.

## Композиции

1. Главная: основной материал / боковая колонка → указатель с текстовым вступлением → тематический разворот → маршруты по механикам и подборка.
2. Каталог: поиск во всю рабочую ширину → боковые фильтры / строки игр. Дополнительный режим обложек.
3. Досье: заголовок и провайдер → изображение / суть и характеристики → оглавление / материал → связанные игры.
4. Статья: заголовочная полоса → широкая диаграмма → узкий текст с полем → связанные материалы.
5. Подборка: вводная идея с парой изображений → последовательные пронумерованные разборы разной длины.
6. Справочник: крупное объяснение → текстовые маршруты с разделителями.

## Мобильное поведение

На ширине до 600 px: короткая навигация остаётся доступна, меню открывает второй уровень; поиск обозначен узнаваемым символом. Боковая история превращается в компактную строку с изображением. Фильтры каталога раскрываются перед результатами; выбранные значения продолжают действовать после закрытия. Обложка и название игры остаются рядом. Оглавление становится компактным набором якорей. Сравнение прокручивается внутри собственной области, не расширяя страницу.

Анимация только у изображения при hover, отключается при reduced motion. Есть skip link, focus-visible, aria-expanded, aria-current, aria-pressed, объявление количества результатов и семантические заголовки таблиц.
