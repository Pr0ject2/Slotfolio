# Refinement 12 — профили провайдеров, механики и системный аудит

Итерация развивает v121 без смены визуальной концепции Astra.

## Провайдеры

- Семь страниц студий стали полноценными редакционными профилями.
- Статистика вычисляется из общей базы: число досье, диапазон RTP, механики, особенности, волатильность и геометрия поля.
- Выборка явно отделена от полного портфеля провайдера и не используется как рейтинг студий.
- Добавлены характерные игры, редакционные маршруты, переходы к фильтрованному каталогу и кнопки сравнения.

## Механики

- Пять страниц механик получили отдельные объяснения принципа, последовательности событий, отличий, ограничений и вопросов к правилам.
- Сводки по RTP, волатильности, особенностям и представленным студиям вычисляются из фактической выборки Slotfolio.
- Игры с несколькими механиками участвуют во всех соответствующих группах.

## Системные исправления

- RTP-парсер теперь отвергает некорректные и выходящие за диапазон значения.
- Редкие особенности доступны в фильтре каталога и сохраняются в URL.
- Поиск лучше обрабатывает русские алиасы и десятичную запятую.
- Сравнение нормализует localStorage, убирает дубли и остаётся работоспособным при недоступном хранилище.
- Ссылки и формы учитывают basePath GitHub Pages.
- Canonical, Open Graph и Twitter URL формируются как абсолютные адреса с учётом `/slotfolio`.
- Для игровых изображений добавлен локальный fallback без изменения заданных размеров.
- В проект включены локальные WebP для всех текущих игровых обложек; runtime не зависит от внешних CDN.

## Проверка

- TypeScript typecheck проходит.
- Чистые data-level Playwright проверки проходят для таксономии, поиска, RTP, досье и 4060 сочетаний по три игры.
- Astra ранее выполнила браузерный и screenshot QA основной версии изменений; финальная правка fallback изображения внесена после этого прогона.
- Повторный production build в текущем Linux-окружении не выполнен: архив содержит Windows node_modules, а сети для загрузки Linux optional dependencies `sharp` и `@next/swc-*` нет.
