# Проверка готового каркаса

7 сентября 2026. Проверка выполнена на локальной production-сборке в установленном Google Chrome через Playwright. Подключённые браузеры приложения недоступны; использовался отдельный headless Chromium.

## Результат

- `npm run build` — успешно, Next.js 16.3.4, 35 сгенерированных страниц/служебных результатов сборки.
- `npm run typecheck` — успешно.
- Предыдущий полный `npm test` — **7 тестов прошли**, итоговый прогон 20 секунд. В v118 добавлен восьмой тест локальности игровых изображений; полный сетевой прогон v118 в текущем контейнере не выполнялся.
- После финальной правки размеров заголовка GEO, подвала на 320 px и изображений сравнения повторно прошли 2 затронутых сценария: все размеры viewport и реальная прокрутка к якорю статьи (10,4 секунды). Production-сборка повторно успешна.
- Проверен 31 публичный маршрут; у каждой страницы один H1 и непустой title с именем проекта.
- Внутренние ссылки, включая отфильтрованные URL, и все ссылки на локальные изображения проверены HTTP-запросами.
- Ошибок JavaScript при обходе страниц нет.
- Переполнения viewport нет на 320, 390, 768, 1024 и 1440 px для главной, каталога, досье, статьи, подборки и GEO.

## Сценарии

1. Запрос `bonanza` → две игры; фильтр Play’n GO → пустая выдача; сброс → двенадцать игр.
2. Каскады + сортировка по названию сохраняются при перезагрузке; режим обложек переключается.
3. Три игры добавляются в сравнение; четвёртая показывает ограничение; выбор сохраняется; удаление обновляет досье.
4. Мобильное меню открывает второй уровень и закрывается после перехода; мобильные фильтры раскрываются; FAQ открывается.
5. Поисковый URL восстанавливает провайдера и сортировку; оглавление длинного материала ведёт к существующим разделам.
6. Неизвестные страницы, игры, провайдеры, механики и операторы возвращают 404. Неподключённый `/go/1win` перенаправляет на disclosure.
7. Проверена ширина страниц в пяти размерах viewport.

## Визуальная оценка

Снимки главной, каталога, профиля игры, длинного материала и подборки созданы на desktop 1440×1000, tablet 768×1024 и mobile 390×844. Просмотрены основные композиции, длинная полоса статьи и мобильное досье. Дополнительно сохранены пустая выдача, открытые фильтры, сравнение, мобильное чтение и GEO на 320 px.

После первого просмотра исправлены растягивание мобильной иллюстрации, качество основной игровой обложки и пробел в заголовке desktop. После функционального прогона исправлены повторный H1, статус неизвестных динамических адресов и перенос длинного заголовка.

## Практические границы

Это завершённый визуальный и структурный фундамент, пока не опубликованный как полноценный сайт. CMS, промышленная пагинация/индекс поиска, матрица доступности операторов по странам, реальные рекламные предложения и редакционные контакты ещё не подключены. Числа RTP отмечены как справочные и требуют редакционной проверки конкретной версии. Доступность соблюдается семантикой и клавиатурным фокусом; отдельная сертификация WCAG, тесты экранным диктором и проверка Safari не проводились.

## Refinement 08 — медиаслой

Для v118 добавлены статические проверки локальных путей изображений и runtime-проверка отсутствия внешних `<img>`. Синтаксис build-time скрипта проверен через `node --check`. Полный сетевой проход локализатора в текущем контейнере не выполнялся: окружение не разрешает исходящие DNS/HTTP-запросы. Поэтому итоговую загрузку шести новых исходников проверяет обычная GitHub Pages сборка, где `prebuild` запускается автоматически и останавливает публикацию при ошибке.
