# Refinement 07 - SEO readiness

Версия v117 не меняет визуальный язык Slotfolio. Итерация готовит текущую структуру к поисковой индексации, не включая её автоматически.

## Что изменилось

- Добавлен единый helper для canonical URL, Open Graph, Twitter metadata и абсолютных адресов.
- Канонический публичный origin берётся из `NEXT_PUBLIC_SITE_URL`, поэтому GitHub Pages корректно учитывает подпапку репозитория.
- Создан `/sitemap.xml`, который автоматически собирает статические разделы, все игровые досье, механики, провайдеров и системные страницы.
- `robots.txt` теперь переключается через `NEXT_PUBLIC_INDEXABLE`.
- Пока индексация выключена, сайт сохраняет прежнее поведение `noindex` + `Disallow: /`.
- При включении индексации robots открывает обход и добавляет Sitemap.
- `/search` и `/compare` всегда остаются `noindex`, потому что это служебные/персонализированные состояния, а не самостоятельные посадочные страницы.
- Для основных разделов и динамических страниц добавлены descriptions, canonical URL и social metadata.
- Игровые досье получили JSON-LD с `Article`, описываемой сущностью `Game` и `BreadcrumbList`.
- Корневой layout публикует базовый `WebSite` JSON-LD.
- В GitHub Actions добавлена поддержка repository variable `NEXT_PUBLIC_INDEXABLE`.
- Playwright-сценарий расширен проверками canonical, Open Graph, JSON-LD, robots и sitemap.

## Включение индексации

До публичного запуска ничего менять не нужно. Для включения:

1. Проверить факты, изображения, юридические страницы и публичный адрес.
2. В GitHub создать repository variable `NEXT_PUBLIC_INDEXABLE` со значением `true`.
3. Пересобрать GitHub Pages.
4. Проверить `/robots.txt` и `/sitemap.xml` на опубликованном адресе.

`NEXT_PUBLIC_SITE_URL` уже выставляется workflow в адрес `https://<owner>.github.io/<repo>`.

## Что сознательно не сделано

- Не включалась индексация автоматически.
- Не создавались искусственные SEO-страницы под ключевые слова.
- Не добавлялись фальшивые оценки, рейтинги или review markup.
- Внешние изображения шести новых игр пока остаются внешними источниками; их локализация остаётся отдельной задачей.
