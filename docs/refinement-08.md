# Refinement 08 — локальные игровые изображения

7 сентября 2026.

## Цель

Убрать загрузку игровых обложек со сторонних CDN в браузере и привести медиаслой каталога к одному предсказуемому формату.

## Что изменено

- Все `Slot.image` и `featureImage` переведены на локальные пути `/images/slots/*.webp`.
- Шесть существующих локальных обложек и крупная иллюстрация Gates of Olympus перекодированы в WebP без апскейла. Их суммарный вес уменьшился примерно с 1,78 МБ до 266 КБ (около 85%).
- Для шести добавленных в v116 игр создан build-time локализатор `scripts/localize-slot-images.mjs`.
- Локализатор скачивает только отсутствующие исходники, ограничивает размер ответа, делает до трёх попыток, проверяет тип контента, кэширует исходник и конвертирует его через Sharp в WebP с ограничением до 1200×675.
- Production-сборка завершается ошибкой, если обязательный локальный asset не удалось подготовить: это не позволяет случайно выложить каталог с битой картинкой.
- Для локальной разработки используется мягкий режим `predev`, который сообщает о проблеме, но не блокирует запуск Next.js.
- GitHub Actions кэширует `.asset-cache/slot-images` между сборками.
- В тестах добавлена проверка, что публичные `<img>` не содержат `http://` или `https://`, а все игровые пути заканчиваются на локальный WebP.
- Основное изображение досье получает `decoding=async`; приоритетное изображение дополнительно получает высокий fetch priority.

## Что важно

`docs/image-sources.json` остаётся журналом исходных URL. Эти адреса нужны только для подготовки локальных файлов и не попадают в runtime-разметку сайта.

В рабочем окружении ChatGPT внешняя сеть контейнера недоступна, поэтому шесть новых бинарных WebP не были скачаны в этот архив напрямую. Они создаются автоматически перед `npm run build` и в GitHub Pages workflow. Уже имеющиеся семь локальных изображений оптимизированы и включены в архив.
