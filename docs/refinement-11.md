# Refinement 11 — richer dossiers and verified metrics

Цель прохода: сделать 30 игровых досье содержательнее без превращения Slotfolio в таблицу случайных чисел.

## Что изменено

- В каждое досье добавлен отдельный блок функций и бонусов: одна уникальная ключевая функция игры плюс объяснения трёх нормализованных особенностей.
- Добавлен математический профиль с RTP, волатильностью, полем, подтверждёнными RTP-конфигурациями и максимумом выплаты там, где публичный официальный источник это явно указывает.
- Различается максимальная выплата и highest observed win: Push Gaming не переименовывается в «max win», если провайдер использует другую формулировку.
- Добавлен контекст относительно текущего каталога: RTP против медианы базы, положение волатильности и ближайшие игры по структуре.
- Сравнение до трёх игр теперь показывает RTP-конфигурации и подтверждённый максимум, а при отсутствии публичного значения честно пишет об этом вместо догадки.
- Дополнительные числовые источники вынесены в `src/lib/dossier.ts`, чтобы не смешивать редакционное описание и верифицированные метрики.

## Подтверждённые источники

Использованы публичные страницы и релизы самих Pragmatic Play, Push Gaming, Hacksaw Gaming, Nolimit City, NetEnt и Relax Gaming. Для игр без однозначно опубликованного значения дополнительный максимум не добавлялся.

## Важное ограничение

RTP и другие числовые параметры относятся к конкретным математическим конфигурациям. Досье по-прежнему предлагает проверять справку внутри реально запущенной версии игры.
- Исправлен справочный RTP Chaos Crew 2: `96,27%` по текущей официальной странице Hacksaw Gaming.
- Переход «Открыть таблицу сравнения» из досье теперь добавляет текущую игру в свободное место сравнения через `?seed=`.
